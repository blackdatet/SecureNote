# SecureNote

### Защищённое хранилище заметок и инцидентов

Учебное Android-приложение для ведения журнала событий
информационной безопасности и фотофиксации.

**Статус: подготовка к разработке**

</div>

---

## О проекте

SecureNote предназначен для регистрации подозрительных событий:
фишинговых писем, попыток несанкционированного входа, возможных утечек
данных и других инцидентов информационной безопасности.

Пользователь авторизуется, создаёт запись, указывает категорию,
уровень опасности и статус, при необходимости прикрепляет фотографию.
Данные сохраняются через backend, запущенный локально на компьютере.
Доступ к записям и вложениям ограничивается их владельцем.

Проект разрабатывается в рамках дисциплины
**«Разработка мобильных компонент анализа безопасности
информационно-аналитических систем»**.

## Цель

Разработать Android-приложение для ведения личного журнала инцидентов
с авторизацией, сохранением данных через локальный backend
и использованием камеры устройства.

## Требования

| Требование | Планируемая реализация |
|---|---|
| Android-приложение | Разработка в Android Studio на Kotlin |
| Авторизация | Регистрация, вход по электронной почте и паролю, выход |
| Работа с backend | Создание, получение, изменение и удаление записей через API |
| Использование камеры | Создание фотографии и прикрепление к инциденту |
| Защита данных | Проверка прав доступа к записям и вложениям на сервере |

## Планируемые возможности

- Регистрация и авторизация пользователей.
- Создание, просмотр, редактирование и удаление записей.
- Категории: фишинг, подозрительный вход, утечка данных, другое.
- Уровни опасности: низкий, средний, высокий.
- Статусы: новый, в работе, закрыт.
- Фотофиксация события с помощью камеры.
- Фильтрация записей по категории, уровню опасности и статусу.
- Сводка по количеству и состоянию инцидентов.

Указанные возможности находятся в плане разработки.
Готовность будет отмечаться после реализации и проверки.

## Технологии и архитектура

| Компонент | Решение |
|---|---|
| Среда разработки | Android Studio |
| Язык Android-приложения | Kotlin |
| Интерфейс | Jetpack Compose, Material 3 |
| Логика экранов | ViewModel |
| Обмен данными | API локального backend |
| Хранение записей | База данных на компьютере с backend |
| Хранение фотографий | Файловое хранилище backend |
| Сборка | Gradle |
| Контроль версий | Git и GitHub |

Android-приложение отвечает за интерфейс, работу с камерой
и отправку запросов. Backend выполняет авторизацию,
проверяет права доступа и работает с базой данных и файлами.

Серверная часть запускается локально на компьютере.
Аренда сервера и облачные сервисы не требуются.
Технологии реализации backend и базы данных будут уточнены
при подготовке серверного модуля.

Для демонстрации используется эмулятор Android Studio
или Android-устройство в одной локальной сети с компьютером.
Компьютер и backend должны быть включены и доступны приложению.

## Планируемые меры защиты

- Проверка авторизации при обращении к защищённым функциям API.
- Проверка владельца при доступе к записям и фотографиям.
- Хранение паролей в виде стойких хешей с солью.
- Проверка входных данных и ограничение размера загружаемых файлов.
- Отсутствие паролей и секретных ключей в репозитории.
- Настройка HTTPS для передачи учётных данных и содержимого записей.
- Проверка изоляции данных с помощью двух тестовых аккаунтов.

Сквозное шифрование содержимого в первую версию не входит.

## Проверка приложения

| Сценарий | Ожидаемый результат |
|---|---|
| Регистрация и вход | Пользователь получает доступ к своему журналу |
| Неверный пароль | Приложение сообщает об ошибке входа |
| Создание и изменение записи | Данные сохраняются на сервере |
| Повторный запуск | Сохранённые записи доступны после входа |
| Удаление записи | Запись и её вложения удаляются |
| Добавление фотографии | Снимок сохраняется и открывается из карточки |
| Обращение к чужой записи или фотографии | Backend запрещает доступ |
| Backend недоступен | Приложение сообщает об ошибке и не подтверждает сохранение |
| Камера недоступна или съёмка отменена | Запись можно сохранить без фотографии |
