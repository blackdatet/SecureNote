# SecureNote

### Защищённое хранилище заметок и инцидентов

Android-приложение для регистрации событий информационной безопасности,
хранения заметок и прикрепления фотоматериалов.

**Статус: проектирование и подготовка к разработке**

</div>

## О проекте

SecureNote — учебный проект мобильного приложения, которое позволяет
пользователю фиксировать подозрительные события и инциденты информационной
безопасности в личном журнале.

Каждая запись объединяет описание события, категорию, уровень опасности,
статус обработки и прикреплённую фотографию. Данные сохраняются на сервере,
а доступ к записям и вложениям ограничивается их владельцем.

Проект разрабатывается в рамках дисциплины
**«Разработка мобильных компонент анализа безопасности
информационно-аналитических систем»**.

## Цель проекта

Разработать Android-приложение для ведения личного журнала инцидентов
информационной безопасности с авторизацией пользователей, серверным
хранением данных и использованием камеры устройства для фотофиксации событий.

## Пример использования

Пользователь обнаруживает подозрительное письмо:

1. Авторизуется в приложении.
2. Создаёт запись «Подозрительное письмо с вложением».
3. Выбирает категорию «Фишинг» и указывает уровень опасности.
4. Добавляет описание и фотографию.
5. Сохраняет запись на сервере.
6. После проверки события меняет его статус на «Закрыт».

## Требования и план реализации

| Требование | Планируемая реализация |
|---|---|
| Android-приложение | Нативное приложение на Kotlin |
| Авторизация | Регистрация, вход по электронной почте и паролю, выход |
| Работа с backend | Создание, получение, изменение и удаление записей через сервер |
| Использование аппаратных возможностей устройства | Фотофиксация события с помощью камеры |
| Связь с информационной безопасностью | Журнал инцидентов и разграничение доступа к данным пользователей |

## Планируемые возможности

### Учётная запись

- Регистрация и вход по электронной почте и паролю.
- Обработка ошибок авторизации.
- Выход из учётной записи.

### Журнал инцидентов

- Создание, просмотр, редактирование и удаление записей.
- Название и подробное описание события.
- Категории: фишинг, подозрительный вход, утечка данных, другое.
- Уровни опасности: низкий, средний, высокий.
- Статусы: новый, в работе, закрыт.
- Дата создания записи.
- Фильтрация записей по категории, уровню опасности и статусу.

### Фотоматериалы

- Создание фотографии с помощью камеры устройства.
- Прикрепление фотографии к записи.
- Загрузка фотографии в серверное хранилище.
- Просмотр вложения из карточки инцидента.

### Сводка

- Общее количество зарегистрированных инцидентов.
- Распределение записей по категориям.
- Количество открытых и закрытых инцидентов.

> Перечисленные функции входят в план разработки.
> Их готовность будет отмечаться по мере реализации и проверки.

## Архитектура

Приложение будет разделено на три основные части:

- **Интерфейс:** экраны авторизации, журнала, карточки инцидента и сводки.
- **Логика приложения:** обработка действий пользователя, проверка ввода
  и управление состояниями экранов.
- **Работа с данными:** авторизация, запросы к базе данных
  и загрузка вложений.

Серверная часть отвечает за хранение данных и проверку прав доступа.
Ограничения доступа должны действовать на сервере независимо
от поведения мобильного интерфейса.

## Планируемые меры защиты

- Доступ к пользовательским данным после авторизации.
- Проверка владельца записи при чтении, создании, изменении и удалении.
- Закрытое хранилище фотоматериалов с проверкой прав доступа.
- Передача данных по HTTPS.
- Отсутствие паролей пользователей и административных ключей
  в исходном коде приложения.
- Проверка изоляции данных с помощью двух тестовых аккаунтов.

В первой версии защита строится на авторизации и разграничении доступа.
Сквозное шифрование содержимого не входит в заявленные возможности.

## Проверка работоспособности

При подготовке демонстрационной версии планируется проверить:

| Сценарий | Ожидаемый результат |
|---|---|
| Регистрация и вход | Пользователь получает доступ к своему журналу |
| Неверный пароль | Приложение показывает понятную ошибку |
| Создание записи | Запись сохраняется на сервере |
| Повторный запуск | Сохранённые записи загружаются после входа |
| Изменение и удаление | Изменения сохраняются на сервере |
| Добавление фотографии | Вложение доступно из карточки записи |
| Вход под другим аккаунтом | Чужие записи и вложения недоступны |
| Отсутствие интернета | Приложение сообщает об ошибке без ложного подтверждения сохранения |
| Недоступность камеры или отказ в разрешении | Текстовую запись можно создать без фотографии |

Результаты проверок будут опубликованы после реализации соответствующих функций.
